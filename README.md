# HostMyWeb

Production website for **HostMyWeb.co**.

## Stack

- Next.js App Router
- Vercel
- Supabase
- GitHub repository: `rawillia9801/hostweb`

The public setup/contact form writes to `public.hostmyweb_leads` in the connected Supabase project using a publishable key and an insert-only RLS policy.

## Product positioning

HostMyWeb is the broad infrastructure brand for managed hosting, domains, business email, DNS, SSL, migrations, and website operations. It is not limited to the dog-breeding market. It also powers purpose-built sibling products including MyDogPortal, DogBreederWeb, and DogBreederDocs.
